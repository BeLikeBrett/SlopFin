# DualSense controls

## Browsing

| Control | Action |
| --- | --- |
| D-pad | Navigate rows, artwork and menus |
| Right stick | Scroll libraries, Discover and Settings; held, it speeds up to double after about a second |
| Cross | Select or play |
| Circle | Go back |
| L1 / R1 | Switch between the **Home** and **Discover** tabs |
| Triangle | Search (Home, libraries and Discover) |
| Square on Home, libraries and Discover | Open your profile menu |
| Hold L2 or R2 + Up/Down | Switch category in the current tab's sidebar |

The top bar holds two tabs. **Home** is your Jellyfin library: its sidebar lists
Overview, your libraries and Settings. **Discover** is the request server: its
sidebar lists Trending, Popular, Top rated, New releases, Upcoming and Requests.
Each tab keeps its own place, so L1 returns to the library and card you left.

Search separates Movies, Series and Episodes. Up/Down changes result rows;
Left/Right browses within a row. A search inside a library keeps that scope.

A compact L2/R2 hint at the bottom of the sidebar lights while a trigger is held.

In **Discover**, Triangle searches the request server and Circle clears that
search. Up from the first row reaches the All / Movies / Series filter, where
Left/Right choose; L3 cycles it from anywhere. Scrolling down loads more titles.
In a title, choose seasons and quality with the D-pad; Triangle opens a season’s
episode guide. Options focuses the primary action. Existing requests show Cancel
when permitted; available media opens in Jellyfin. See [Discover](DISCOVER.md).

Use **Settings → Navigation** to show or hide the Discover tab, and to show, hide
or reorder Overview and your libraries. Cross toggles visibility, L1/R1 move a
category, and Square restores the default layout. Settings stays visible. Controller options are inside Navigation.
New libraries appear automatically; renaming a library keeps its saved position.

## Playback and seeking

| Control | Action |
| --- | --- |
| Cross | Pause/resume, or activate the focused playback control |
| L2 / R2 | Rewind / fast-forward: tap one second; hold and press deeper for faster scrubbing |
| D-pad Left/Right on the timeline | Tap ten seconds; hold to scrub |
| L1 / R1 | Jump back / forward two minutes |
| Up | Show/focus the timeline |
| Down | Move from the timeline to the lower playback controls |
| Circle | Back out of a panel/control, hide the controls, then leave playback |
| Touchpad or R3 | Toggle playback diagnostics |

DualSense adaptive triggers add resistance during playback. Switch it off in
**Settings → Navigation → Controller → Trigger feedback**. Seeking still works with feedback
off or with a controller that cannot apply the effect.

The picture pauses while you aim a seek and resumes in its previous state
when the seek commits after you release. Moving back to the starting position
cancels the seek. Restarting a stream can take time, especially with transcoding.

When Skip Intro is visible, **Square** always skips. Outside intros, Square
toggles subtitles. **Cross** keeps its pause/select role. Circle dismisses an intro or
Up Next card when the normal controls are hidden.

## Subtitle appearance

Settings → Subtitles has separate text and picture controls. Blu-ray PGS and
DVD overlays preserve their font and colours, with adjustable size and
Original/Bottom/Higher/Top placement. During picture-subtitle playback, open
Options → Subtitles and scroll past the tracks and timing controls to change
picture size/position with Left/Right or Cross. Changes apply immediately and
are saved; Back to original picture layout restores size and placement.
Timing is saved per title and applies to text and PS5 picture overlays.
Server-burned subtitles keep the server's layout.

## Text and pictures

Text fields use the PlayStation keyboard. Confirm applies the text; cancel
keeps the previous value. SlopFin requests the search keyboard below
the field and clears artwork while typing; the PS5 controls final placement.

In the picture editor, D-pad moves the circular crop,
L1/R1 or the triggers zoom, Triangle resets, Cross saves and Circle goes back.

The right stick also scrolls the Settings category list. Updates is at the bottom.
