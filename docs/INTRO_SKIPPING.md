# Skip Intro

SlopFin shows **Skip intro** while playback is inside an episode's detected
intro. It seeks to that intro's end, so cold opens and different intro lengths
can be handled without a fixed-duration skip.

- **Square** skips with or without the playback controls visible.
- **Cross** keeps its pause/select role.
- **Circle** dismisses the prompt when the normal controls are hidden.

A failed seek keeps the button available for another attempt. Open audio,
subtitle or quality panels temporarily hide it.



## Set up your server

The server needs usable intro timestamps. Jellyfin's
[media segments](https://jellyfin.org/docs/general/server/metadata/media-segments/)
are generated by providers and made available to clients.

The setup is the same on any Jellyfin server; SlopFin does not require a
particular server address, a separate PS5 plugin, or manually entered times.

1. In the Jellyfin server dashboard, install a media segment provider compatible
   with your Jellyfin version. [Intro Skipper](https://github.com/intro-skipper/intro-skipper)
   detects intro/credit sequences automatically. Jellyfin's official **Chapter
   Segments Provider** can use appropriately named chapters already in files.
2. Follow that provider's setup and run its analysis task if it has one. Then
   run **Dashboard → Scheduled Tasks → Media segment scan** to publish segments.
   Keep automatic scanning enabled for new episodes.
3. Reopen the episode in SlopFin after scanning. **Skip intro** appears during
   its marked intro; press **Square** to skip. No web-client patch is needed.

SlopFin reads the standard Jellyfin `/MediaSegments/{itemId}` API and `Intro` /
`Outro` records. Any compatible provider that publishes those records can work;
the client does not depend on a provider-specific endpoint. See Jellyfin's
[standard media-segment setup](https://jellyfin.org/docs/general/server/metadata/media-segments/).

SlopFin checks Jellyfin Intro segments first. If none are available, it accepts
explicitly named Intro/Opening/Opening Credits/Opening Theme/Title Sequence or
OP chapters, using the next chapter as the end. Generic first chapters, recaps,
missing end times and implausible ranges do not become intro buttons.

Changing or unique intros can lack markers. If an episode has no usable range,
there is no skip button. Installing SlopFin does not analyze episode audio.

**Next-episode autoplay is built into SlopFin and needs no segment plugin.**
It uses Jellyfin's episode order/Next Up data. Outro markers let the next-episode
card appear at the credits; without them, it uses the normal end-of-episode
fallback. Configure it in **Settings → Playback**. Marker generation requires
server administrator access; viewers on a shared server use its existing markers.
