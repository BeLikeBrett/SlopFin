# Public interface captures

`home-console.png` and `media-console.png` are direct SlopFin 2.00 candidate
captures from PS5 firmware 8.20 on 2026-10-23, at 1920×1080 from the native 4K
render surface. They show the updated GPU interface and transparent resting
media actions. The media capture includes the approved Resume progress ring.
Account, server and library names are published with the
owner's existing permission. No credentials are visible.

`subtitles-preview.png` uses the actual Linux application renderer and packaged
fonts from the same candidate. It shows independent text, outline and
background colour settings. It contains no media or account data.

`requests-console.png`, `welcome-console.png` and
`signin-console.png` are direct SlopFin 1.14 captures from a PS5 running
firmware 8.20 on 2026-10-18, converted from the console's JPEG XR screenshots and
scaled to 1920x1080. They show the developer's real Jellyfin Home, request list
and sign-in screens, with permission to publish the account, server and library
names. The server address is blurred on the welcome and sign-in pages, and the
console's own screenshot notification is removed from the sign-in capture. Media
artwork belongs to its respective owners; it is displayed as part of the client
interface, not distributed as app assets. No credentials are visible; the Quick
Connect code had expired.

`avatar-crop-console.png` shows the circular editor using a console capture
as its source photo; the edit was cancelled without changing the profile.
`skip-intro-control.png` is a full-resolution crop of the corrected rounded
button. Both were captured on the PS5 on 2026-10-03.

`discover-preview.png`, `request-preview.png` and `navigation-preview.png` show
the 1.11 Home / Discover tab layout in the Linux renderer on 2026-10-18, served
by a local stand-in Jellyfin and Jellyseerr. The account, library, request and
download data are fictional; titles, posters and stills are public TMDB catalog
metadata and artwork displayed through the client. Media artwork belongs to its
respective owners and is not bundled as app assets. No credentials are visible.
`request-preview.png` shows a series with a subset of seasons selected; no
request was submitted for the capture.

`discover-preview.png` was refreshed for 1.12 using the same fictional fixture.
It shows the right-stick prompt and All/Movies/Shows filter. The R3 control cycles all three
states without moving the catalog focus.

`updates-console.png` is a direct full-resolution PS5 capture of SlopFin 1.10,
showing the installed version/update check. The owner authorized publishing the
displayed account/library names. No credentials are visible.

The Linux preview does not play video or implement the PlayStation system
keyboard. System keyboard overlays are also absent from SlopFin's own console
captures. Playback evidence is documented separately.
