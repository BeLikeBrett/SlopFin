# Public interface captures

`home-console.png` is a direct SlopFin capture from a PS5 running firmware 8.20
on 2026-10-03. It shows the developer's real Jellyfin Home/library with permission
to publish. Media artwork belongs to its respective owners; it is displayed as
part of the client interface, not distributed as app assets. No credentials are
visible.

`avatar-crop-console.png` shows the circular editor using a console capture
as its source photo; the edit was cancelled without changing the profile.
`skip-intro-control.png` is a full-resolution crop of the corrected rounded
button. Both were captured on the PS5 on 2026-10-03.

`home-preview.png` shows the Linux renderer with a fictional account/library
and original project-authored geometric artwork covered by the project license.

`settings-preview.png`, `navigation-preview.png`, `discover-preview.png` and
`request-preview.png` show the 1.10 Linux renderer on 2026-10-16. Connection and
request data are fictional; Discover uses public TMDB catalog metadata and
artwork displayed through the client. Media artwork belongs to its respective
owners and is not bundled as app assets. No credentials are visible. `request-preview.png` shows an unrequested series
with a subset of seasons selected; no request was submitted for the capture.

`downloads-console.png` and `updates-console.png` are direct full-resolution PS5
captures of SlopFin 1.10, showing an active request download and the installed
version/update check. The owner authorized publishing the displayed
account/library names. No credentials are visible.

The Linux preview does not play video or implement the PlayStation system
keyboard. System keyboard overlays are also absent from SlopFin's own console
captures. Playback evidence is documented separately.
