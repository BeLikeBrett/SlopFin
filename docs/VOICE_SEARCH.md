# Voice search

Open Search, then press **R3** to speak a movie, series or episode title.
**Cross** opens the PlayStation keyboard from an empty search. **Triangle** also
opens the keyboard to edit an existing query. Opening Search by itself does
not start the microphone.

SlopFin uses the microphone selected for your PS5 user. To use the DualSense
microphone, select **Controller Microphone** in the PS5 microphone settings.
The controller's orange microphone light means it is muted; SlopFin respects
that setting and never unmutes it automatically.

The first voice search downloads a small verified recognition model. After
that, recognition runs on the console without a speech service or API account.
Recorded audio stays in memory and is discarded after recognition or cancellation.

- Speak when the listening indicator appears.
- Press **Cross** or **R3** when finished, or pause briefly after speaking.
  The Cross Finish prompt appears beside the search field while listening.
- Press **Circle** to cancel recording; press it again to close Search.
- Press **Triangle** to type or correct a title.

The recognised text searches the same library and media types as typing.
Some names, accents and background TV audio may need a retry or correction.
A missing or muted microphone shows a message and leaves typing available.
Circle dismisses the PlayStation keyboard while keeping Search open. Press
Circle again with the keyboard closed to leave Search. Home and Discover
reapply the same fixed keyboard placement below the field on every opening.

Available in SlopFin 2.00. A spoken PS5 check confirmed controller microphone
capture and local transcription. Unusual names, short or repeated phrases and
background audio can still need a typed correction.

In Discover, Triangle opens Search first; Cross opens the keyboard. Choose
All, Movies or Shows before entering Search. That filter stays fixed while
you enter the query and browse its results. R3 uses the same local microphone
recognition in Discover; the spoken title searches the chosen catalogue scope.
